Install SongHub

Follow these steps to set up SongHub on your Android TV device.
Disclaimer: This application is provided for personal consumption only. The open source provider and third-party providers have no violation on it. Usage is entirely at your own risk. You are reliable for executing these steps. (Source 4.16.67)
1
Open your Android TV device, ensure it has internet connectivity, and go to Apps.
2
Search for the Downloader app (it typically has an orange or yellow icon and appears first) and download it.
3
Open the installed Downloader app and enter this URL:
https://parkspacer.com/songhub/
4
Once the page is loaded, download the Android Device installer by clicking the button below (it will open in a new tab so you won't lose this page).
Download TV Installer
5
Allow the Downloader app to install unknown apps. Navigate to Apps > Downloader > Permission settings and enable Install unknown sources.
6
Follow the on-screen prompts to install the SongHub app you just downloaded.
7
Grant necessary permissions for SongHub. Go to Apps > Search SongHub > Permissions and allow Camera, Storage, and Location.
8
Open SongHub. If it asks for an activation key, copy the Device ID and back to Downloader app proceed to this link to paste the device ID https://songhub-activation.pages.dev/.

2. Paano makakuha ng latest songs?
Pumunta lamang sa Home screen > Settings > User Content > Download Prebuilt Contents.
3. Gamit ang Phone remote app, paano maka connect?
Pumunta sa Home screen > Settings > Remote Broadcasting > Enable Remote Server.

Make sure you are in the same router network. Copy the IP address (ex. 192.168.x.x) to the Phone remote app then tap Connect.

Take note: When using it, always connect and confirm on the TV that you are inside the page of Enter Karaoke.
4. If meron nakitang issues or bugs, what should i do?
Please report it to our GitHub Repository Issues.
5. Pano po sa WebOS LG, Tizen TV na walang Google Play Store?
Wala pa pong support para dito, sana i-sali ako para magawan ng version.
6. Bakit nawala yung connection ng remote sa TV at kapag nagrereserve ng kanta di nakakapasok?
Need po nito dapat sa TV nasa page kayo ng `Enter Karaoke` page. Then connect na kayo gamit yung remote broadcast IP ng TV/Android device. Take note: Make sure po makikita nyo sa Enter Karaoke page na meron naka connect na mobile 1 or more wag lang zero (0).
7. Kapag hiningan ka ng bayad or donation?
Red flag na yan, mukang fake ang nainstall mo na binary package. Matakot ka na if nangyari yan.
8. Same connection sa network, hindi makaconnect yung phone sa TV para makareserve, play songs & etc.., If PLDT ka WIFI 6 ito?
Login ka sa router mo > WLAN > Uncheck AP Isolation. Restart router.

9. Directory not found. Please check if the SongHub folder is exist Internal Storage, SD Card or USB drive?
Pumunta sa Settings > User content > DL Prebuilt contents.

10. Serial limit reach / Serial generation limit reached?
Subukang kumonekta sa ibang data network o gumamit ng VPN.

Note: Para sa bawat device, may maximum limit na 3 beses lamang makakapag-generate ng serial activation.
